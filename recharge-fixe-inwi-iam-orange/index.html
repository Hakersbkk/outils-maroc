Recharger un mobile ou payer un fixe : ce qu'il faut savoir

Au Maroc, les principaux opérateurs sont Maroc Telecom (IAM), Orange Maroc et inwi. Les méthodes de recharge et de paiement évoluent régulièrement : les informations ci-dessous sont données à titre indicatif. Vérifiez toujours les modalités, les montants disponibles et les éventuels frais auprès de l'opérateur (site officiel, application ou agence).

Recharger un mobile : les méthodes courantes

  • Cartes prépayées (scratch) : achetées chez les revendeurs agréés, kiosques, tabacs ou boutiques de l'opérateur. Grattez le code et saisissez-le selon la procédure indiquée sur la carte.
  • Recharge électronique : chez un revendeur équipé, la recharge est créditée directement sur le numéro, sans carte physique. Demandez un reçu.
  • Code USSD : chaque opérateur propose un code de recharge à taper depuis le téléphone, puis le code de la carte. Le code exact figure sur votre carte, votre application ou le site officiel.
  • Applications mobiles et sites officiels : les apps des opérateurs permettent de recharger son numéro ou celui d'un proche, souvent par carte bancaire ou paiement mobile.
  • Services bancaires et de paiement : applications bancaires, distributeurs automatiques et réseaux de paiement de factures peuvent proposer la recharge, selon les partenariats.

Payer une ligne fixe

  • Le téléphone fixe fonctionne généralement par abonnement avec facture, et non par carte prépayée : il s'agit donc d'un paiement plus que d'une recharge.
  • Canaux usuels : agence de l'opérateur, guichet bancaire, prélèvement automatique, site ou application de l'opérateur, points de paiement agréés.
  • Certaines offres fixes prépayées existent selon les opérateurs et les zones : vérifiez la disponibilité auprès du service client.

Recharger pour un proche ou depuis l'étranger

  • La recharge à distance est possible via les applications et sites officiels, ou auprès d'un revendeur disposant du numéro du bénéficiaire.
  • Depuis l'étranger, privilégiez les canaux officiels de l'opérateur ; des frais ou des limites de montant peuvent s'appliquer.

Vérifier et sécuriser son opération

  • Contrôlez le solde ou la confirmation de paiement après l'opération (code USSD, SMS, application).
  • Conservez le reçu ou la preuve de transaction, utile en cas de litige.
  • N'achetez pas de codes hors circuits agréés et ne partagez jamais un code de recharge non utilisé.
  • En cas d'échec, contactez le service client de l'opérateur avant de racheter.

À vérifier avant de recharger

Les montants de recharge, la durée de validité, les frais éventuels et les procédures peuvent changer. Ces éléments sont à titre indicatif : consultez la source officielle de votre opérateur (site web, application ou agence) pour confirmer.
